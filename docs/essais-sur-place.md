# Essais sur place

La checklist des vérifications manuelles de **media_hub** est désormais tenue
dans [Notion](https://app.notion.com/p/418da06137f281e28dfad05c1f7783c6?pvs=204).

Ce fichier reste volontairement dans le dépôt comme point d'entrée stable pour
les liens existants. Ne pas y ajouter d'essais : mettre à jour la page Notion
avec le connecteur MCP du projet.

Les configurations partagées sont dans `.codex/config.toml` pour Codex et dans
`.mcp.json` pour Claude Code. Aucun jeton Notion n'est stocké dans le dépôt.
